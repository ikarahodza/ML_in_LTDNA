================================================================================
TABPFN EXPLAINABILITY ANALYSIS - PDP & ICE - MIX DATASET
================================================================================

Model: model_tabpfn_original_v35
Dataset: MIX

================================================================================
METHODS USED
================================================================================

1. PARTIAL DEPENDENCE PLOTS (PDP)
   - Shows average effect of a feature on predictions
   - Marginalizes over all other features
   - Global feature effect visualization

2. INDIVIDUAL CONDITIONAL EXPECTATION (ICE)
   - Shows effect of a feature for individual samples
   - Displays heterogeneity in feature effects
   - Gray lines = individual samples, Blue line = average (PDP)

================================================================================
FEATURE SELECTION
================================================================================

Features for PDP/ICE were selected by variance (top 6).
High variance features tend to be more informative for interpretation.

================================================================================
INTERPRETATION GUIDELINES
================================================================================

PDP:
  - Shows how predicted outcome changes with feature value
  - Flat line = feature has no effect
  - Steep slope = strong feature effect
  - Non-linear curves = non-linear relationships

ICE:
  - Gray lines diverging = heterogeneous feature effects
  - Parallel gray lines = homogeneous effects
  - Wide spread = feature interactions present
