================================================================================
HOW TO COMPARE MODELS
================================================================================

1. Look at the same sample across different models
   - See which features each model relied on
   - Compare feature importances between models

2. Look at different samples for the same model
   - See consistency in feature usage
   - Identify patterns in mistakes

3. Compare actual vs predicted classes
   - See which classes each model confuses
   - Identify systematic biases

Feature Contribution:
  - Green bars = feature supports the predicted class
  - Red bars = feature opposes the predicted class
  - Longer bars = stronger influence
