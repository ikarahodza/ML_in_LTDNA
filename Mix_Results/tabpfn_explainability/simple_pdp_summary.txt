TABPFN SIMPLE FEATURE EFFECT ANALYSIS - MIX DATASET
================================================================================

Model: model_tabpfn_original
Dataset: MIX

================================================================================
METHOD
================================================================================

Grid Sampling Feature Effect Analysis:
  - Uses 1 baseline sample with all other features held constant
  - Varies each feature across 10 equally-spaced grid points
  - Shows predicted probability for class 0
  - Optimized for TabPFN (only 60 predictions total vs 1000s for standard PDP)

================================================================================
INTERPRETATION
================================================================================

For each feature plot:
  - X-axis: Feature value range
  - Y-axis: Predicted probability for class 0
  - Upward slope: Higher feature values increase class 0 probability
  - Downward slope: Higher feature values decrease class 0 probability
  - Flat line: Feature has minimal effect on predictions
  - Non-linear curves: Non-linear relationship between feature and prediction
